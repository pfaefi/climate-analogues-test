# Klima-Analog-Spiel: test version

**Test version, not for citation or distribution.** Where would the summer 2026 of a Swiss
place be an ordinary summer today? A game with Street View images from the regions whose
normal summers (1991–2020) are like the summer 2026 at the chosen place.

This repository holds only the built web pages and pre-computed data files of the test
version. It is generated automatically; the code that computes the data is not here.

## Data sources

- Swiss summers: MeteoSwiss, spatial analyses (open data). Source: MeteoSwiss.
- Global summers 1991–2020: CHELSA-monthly v2.1 (Karger et al.), CC0.
- Maps of Switzerland and place search: swisstopo (geo.admin.ch).
- Region and country names: Natural Earth (public domain).
- Images and world maps: Google Street View and Google Maps.
- Rural filter of the image locations: ESA WorldCover 2021 (CC BY 4.0).
